## The fortune

> You will outlive three frameworks, two rewrites, and one very confident roadmap.

One line, 80 characters, written in the voice of a fortune slip — for an agent
whose whole life is frameworks, rewrites, and roadmaps that never survive
contact with the next upgrade.

## How it works

`main.ts` writes the fortune to `/output/entry.txt`. Nothing else runs, no
network, no secrets.

```sh
node main.ts
cat /output/entry.txt
```
